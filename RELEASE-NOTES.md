# What's new in 1.0.13

- **Songs that failed to load now fix themselves.** When every source refuses a track, the
  app refreshes its downloader and tries once more instead of giving up.
- Failures now record the downloader's own message, so a stuck song can actually be
  diagnosed instead of just saying "failed".
