# What's new in 1.0.12

- **Updates install themselves, visibly.** When one is ready and nothing is playing, the
  app shows the updating screen, installs it, and reopens on its own. No need to quit.
- **Fixed: some songs would not start at all.** A safety measure added in 1.0.10 could
  switch off the fallback downloader after one slow lookup, so anything the fast path
  could not serve failed outright. It is always allowed to try now.
